# India boundary data

`ne_10m_admin_0_india.geojson` contains the India feature extracted from
Natural Earth's `ne_10m_admin_0_countries_ind.geojson` dataset at 1:10m scale.
The file uses Natural Earth's India point-of-view boundary and is public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries_ind.geojson

Thermal Watch.AI applies this polygon to each validated FIRMS observation
before storage, clustering, ML inference, risk scoring, or dashboard APIs.
